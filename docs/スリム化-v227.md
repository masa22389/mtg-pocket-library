# v227：ユーザー指定の機能整理

2026-09-14。v226の検索・DB参照の軽量化は維持。

## 実装済み

- コレクション表示：50件・100件・全件を選択。初期値50件。端末に設定保存。50/100件はその件数ずつ追加、表示を減らすと初期件数へ戻る。全件では追加・縮小ボタンなし。集計対象は全件のまま。
- カード詳細の価格欄：採用価格・取得元情報・日時・価格取得ボタン・手動入力・手動価格削除を集約。操作結果メッセージは既存位置を維持。
- 並び替え：コレクションとデッキのボタンをプルダウンへ集約。コレクションは従来の複数条件の追加・解除と優先順位表示を維持。デッキは選択条件で並び替え。
- Visual View・一画面Visual・画像保存、およびOCR・画像ファイル名検索の実装と入口・専用CSSを削除。デッキ統計で共用するタイプ分類は維持して改名。
- CardTraderの高額カード専用取得の入口・処理・設定参照を削除。
- Scryfall参考価格：設定欄で使用を選択可能。既存動作を維持するため初期値オン。オフでは英語版価格補完通信・価格の採用・メタデータ更新時のScryfall価格転記を停止。カード情報・画像取得は維持するためAPIレスポンス内の価格項目の受信自体は続く。以前の価格は削除せず非採用にし、再度オンにできる。既存の取得元優先順位は維持。

新しい表示件数・Scryfall設定は端末内に保存する。今回、既存バックアップ形式は変更していないため、この2設定はJSONバックアップの対象外。

## 説明後に判断する項目（未変更）

### 価格取得ボタンの集約案

現在はWisdom GuildとCardTraderにそれぞれ全量取得ボタンがある。案では上部に「コレクションの価格を更新」を1つ置き、選択した取得元順で実行する。Wisdom Guild成功分はそこで終わり、不一致・失敗分だけCardTraderへ回す。API未設定ならスキップし、結果に理由を表示。手動価格は維持する。

これは配置だけでなく全量取得の実行方法も変わるため、今回は実装しない。Scryfallは別の参考価格設定で管理する。取得失敗時の前回価格の扱いと状態条件は未確定で、別途決める。

### お気に入り管理の集約案

カード詳細には所属グループのチェック欄と「グループ管理」を置く。詳細内の新規作成欄を管理画面へ移し、そこで新規作成・改名・グループ削除をまとめる。既存の管理画面があるため大規模変更は不要。カードからすぐ新規グループを作れる現在の便利さもあるため、今回は現状維持。

### 背景色・為替・説明

現状ですでに設定画面にあり、設定方法の説明は折りたたまれている。背景色と為替をさらに詳細設定へ隠すほどの利点はなく、移動しない。
