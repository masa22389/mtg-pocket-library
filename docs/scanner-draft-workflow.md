# v328 仮リストの操作

## v329の操作変更

一覧のチェック欄と各カードの削除ボタンは廃止。コレクション・デッキ編集と同じ450msの長押しで選択を開始し、18px以上の移動やpointercancelで長押しを中止する。未選択時の通常タップは個別編集、選択中のタップは選択追加・解除。1件以上選択した場合のみ画面下部に「コレクションに追加」「仮リストから削除」を表示する。全選択・選択解除も選択中に利用できる。保存処理とロールバックの仕組みはv328を維持。

スキャナー上部の戻る・タイトル・総枚数ヘッダーを削除。画面移動はメインの下部タブで行う。スキャンパネルは残りの高さを使うflex配置とし、親のナビゲーション高との8pxの計算差と子の下余白を除去した。ブラウザーで320/390/1280px幅の画面下端とフッター上端を検証。実機での新しい長押し操作は未確認。

- 新たなスキャン候補は、画像照合の候補版を基に収録版・言語・仕様を自動で仮設定する。既存の未選択行も仮リストを開いたときに補完する。
- 日本語画像データがある版を優先する。候補版に日本語版が見つからない場合は、同じOracle IDの利用可能な版を初期値にする。カード上のセット・番号やFoilをOCRで確定したものではない。全自動設定は「仮設定」と表示し、個別の版選択画面で変更できる。
- 自動仮設定はローカルの版カタログから行う。スキャン時にScryfallへカード情報を問い合わせない。コレクションへの移動時に版・言語・仕様とOracle IDをAPIで検証する。この検証は版データの存在確認であり、実物の収録版が正しいことの確認ではない。
- 一覧のチェック欄で1件・複数件・全件を選択する。画像・カード名のボタンは個別編集を開く。
- 移動・削除は選択したIDだけが対象。移動は選択全件の情報がそろってから、コレクションへの追加と仮リストからの消去を同じIndexedDBトランザクションで行う。取得・書き込みに失敗した場合は仮リストを残す。削除ではコレクションを変更しない。
- 自動推定のまま保存したカードには `scanPrintingEstimated` を付ける。手動選択した版は自動設定で上書きしない。
- 書き出しボタンは「（デバッグ用）記録・仮リストを書き出す」。

検証：`scanner/tests/printing-default.test.mjs`、`tests/scanner-draft-selection.browser.cjs`（単件・複数件移動、既存枚数への加算、選択外保持、取得失敗、DB書き込み途中のロールバック、再試行、単件・複数削除）、既存の個別削除と日本語画像表示の回帰テスト。スマホ実機での新しい選択操作は未確認。
