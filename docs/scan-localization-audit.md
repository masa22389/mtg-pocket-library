# スキャンの日本語表示：v327データ監査

2026-10-26、認識辞書38,101種をローカルの日本語カードデータ・公式ギャラリー補完辞書・MTGJSON補完辞書と照合した。

- v326は2枚だけの個別修正ではなく、日本語名767件を補完し、未選択の参考画像2,589種について日本語版を参照できる仕組みを追加した。
- v327の追加調査で、各面にのみ保存された日本語名などの取りこぼしが見つかり、96件をさらに補完した。
- 「比較的新しい」は2025-01-01〜2026-10-26の日本語収録版がスナップショットにあるカードと定義。この5,322種について日本語名の欠落は0件。
- 全認識辞書について、日本語画像データが存在するのに参照先が選べないケースは0件。追加参考画像のOracle ID・セット・番号・URL不一致も0件。
- 日本語収録データがあるが日本語名を補完できない47種は残っている。この47種は上記の最近の5,322種には含まれない。
- 最近の収録版を持つが日本語紙カードのスナップショットにない認識IDは1,898種。トークンなども含む。日本語版が存在しないとは断定せず、今回の日本語データ既知カードの検査とは区別する。

これはデータの整合性検査。全種のカメラ認識、画像中の日本語、外枠まで目視確認したものではない。古いカードの外枠未完了事項は `japanese-image-framing.md` を参照。
