# MTG Pocket Library

MTGの所持カード管理・カード検索・デッキ編集を行うための個人向けWebアプリです。

PCブラウザでもAndroidでも使えるよう、静的サイトとして動作します。カード情報の検索には主にScryfall APIと、アプリ内の日本語検索補完DBを使います。

## 主な機能

- 日本語・英語カード名検索
- 所持カードの登録、枚数管理、お気に入り管理
- カード価格の参考表示
- デッキ作成・編集
- メイン / サイド / 統率者 / 候補の管理
- デッキ統計表示
- デッキインポート
- バックアップ / 復元
- 日本語検索補完DB、CSV出力・取り込み

## ローカルでの起動

このフォルダでHTTPサーバーを起動します。

```powershell
cd C:\Users\xsq11\DDM\mtg-pocket
python -m http.server 4174 --bind 127.0.0.1
```

PCでは次のURLを開きます。

```text
http://127.0.0.1:4174/?v=112
```

AndroidをUSB接続してPCのローカルサーバーを見る場合は、ADBでポート転送します。

```powershell
adb reverse tcp:4174 tcp:4174
```

その後、Android Chromeで次を開きます。

```text
http://127.0.0.1:4174/?v=112
```

## データ保存について

所持カード、デッキ、設定などのユーザーデータは、各端末のブラウザ内 `localStorage` に保存されます。

GitHub Pagesなどで公開しても、あなたのPCやスマホに保存されているデータが他の人へ自動共有されることはありません。知り合いが同じURLを開いた場合、その人の端末には空の状態からデータが作られます。

ただし、以下のようなファイルをリポジトリに含める場合は、公開前に内容を確認してください。

- バックアップJSON
- 個人的なメモ
- 手作業で作成したCSV
- 未整理の作業ログ

## 注意

Scryfall APIへの通信が必要な検索があります。ネットワーク状況やScryfall側の制限によって、一時的に検索に失敗する場合があります。

## スキャン機能 v305

検索画面の「カメラでカードをスキャン」から利用します。初回は認識用データ約91MBを自動準備します。カメラの枠にカードを合わせるとスキャンリストへ仮追加します。版・言語・仕様はスキャン後に選択し、確認済みカードを所持カードへ保存できます。詳細と制約は[scanner/README.md](scanner/README.md)を参照してください。

旧スキャナーは scanner-trial/continuous.html に残しています。スキャンリストは新旧で別です。

## スキャナー更新 v307

スキャン画面と画像付き仮リストをタブで分離しました。仮リストでカードを選ぶと、枚数・状態・版・仕様・言語・保管場所を指定してコレクションへ追加できます。本体を開いている間は認識処理を保持し、スキャナーを開き直すたびのモデル再生成を避けます。初回と完全なアプリ再起動後は準備が必要です。詳細はscanner/README.mdを参照してください。

## v308 モバイル入力・所持カード検索

モバイルの入力文字を16px以上にし、iOSの入力フォーカス時の自動ズームを抑制します。手動のピンチ拡大は制限しません。所持カード検索は保存名に加えローカル日本語辞書・各面の名前を利用し、読み仮名と全角/半角を正規化します。英語名だけで保存された出来事カード（厚かましい借り手など）も日本語名で検索でき、保存データの変更・再登録は不要です。

## v309 スキャナー操作の改善

iPhoneの上部安全領域を考慮した戻るボタン、事前準備が完了してからのスキャン画面切替、仮リストのカード単位の削除を追加しました。初回・完全な再起動時の読み込みは必要ですが、準備済みの認識処理は本体を開いている間再利用します。
